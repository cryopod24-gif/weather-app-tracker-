# weather-app-tracker
A simple weather web application that lets users search for any city
and view the current temperature, humidity, wind speed and a 5-day
forecast.

Built for the SWD 417 assignment.

## Live Demo
https://cryopod24-gif.github.io/weather-app-tracker

## Features
- Search weather by city name
- Current temperature, humidity and wind speed
- 5-day forecast (daily minimum and maximum temperature)
- Error messages for unknown cities and network problems

## Technologies Used
- HTML
- CSS
- JavaScript (Fetch API)
- Open-Meteo API (free, no API key needed)

## How to Run
1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Type a city name and tap Search.

An internet connection is required to fetch weather data.
